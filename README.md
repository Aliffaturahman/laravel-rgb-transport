# RGB Transport

RGB Transport is a web-based transportation booking platform designed to facilitate the ordering and management of goods delivery services. The platform allows customers to submit delivery orders and track their shipments, while administrators can manage orders, customers, vehicles, pricing, and shipment information through an administrative interface.

## Features

### Customer

- User registration and authentication
- Create and manage delivery orders
- Enter sender and recipient information
- Add and manage shipment details
- View order information and delivery status
- Track shipments
- View and download invoices

### Admin

- Manage customer data
- Manage delivery orders
- Manage vehicle data
- Manage transportation pricing
- Manage recipient information
- Manage shipment tracking
- View order details
- Generate and manage invoices

## Technologies

### Frontend

- **HTML5**  
  Used to structure the web pages and application content.

- **CSS3**  
  Used to style the interface and create responsive layouts.

- **Bootstrap 5**  
  Used to build the responsive user interface and reusable UI components.

- **JavaScript**  
  Used to implement interactive functionality on the website.

### Backend

- **Laravel**  
  Used as the main PHP framework for developing the application backend, routing, authentication, business logic, and database interaction.

- **Laravel Breeze**  
  Used to implement authentication features such as login, registration, and user session management.

### Database

- **MySQL**  
  Used to store application data, including customers, users, orders, shipment details, vehicles, transportation pricing, recipients, and shipment tracking information.

### Development Tools

- **Vite**  
  Used to manage and build frontend assets during development and production.

- **AOS**  
  Used to implement scroll-based animations.

- **Particles.js**  
  Used to create interactive visual effects on the website.

- **Owl Carousel**  
  Used to create responsive content carousels.

- **DataTables**  
  Used to provide interactive tables for managing and displaying data.

## Project Purpose

RGB Transport was developed to provide a digital platform for managing goods delivery orders while improving the overall user experience of the transportation booking process.

The project also demonstrates the implementation of **full-stack web development**, covering user interface design, frontend development, backend development, database management, authentication, order management, and shipment tracking.
